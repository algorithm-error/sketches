Acknowledge button

Wraps button with a "confirmed" state: on click, the label swaps to a confirmation message (put it in a slot="confirm" element), and it swaps back once the mouse leaves. Useful for actions like "Copy" → "Copied". variant, size, and stretch are forwarded to the inner button as-is.
