Number input

A plain text field for editing a numeric value.

Basic

Commits its value on Enter or blur, and dispatches input/change events with the parsed number. input is debounced 100ms by default; set debounce (ms) to adjust, or debounce="0" to disable.

Cols

cols sizes the field to fit that many digits, like <textarea cols>, with extra room reserved for the native spinner so the digits themselves don't get squeezed.
