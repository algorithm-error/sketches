Grid

A real CSS grid container: display: grid, columns sized to their content (grid-template-columns: repeat(n, max-content)), gap: 1.5rem. Set columns to the number of columns — children wrap onto a new row after that many. Leave a cell empty by dropping in an empty element.

Basic

Five children, three columns — the fourth and fifth wrap to a second row.

Empty cell

An empty element reserves its cell without rendering anything — useful for lining up a grid of examples that doesn't fill evenly, like the hatch sandbox.
