Vertical split

A layout wrapper: two panes side by side, separated by a vertical split. Spans the full width and splits it 50 / 50 by default.

Basic

Two children, two equal columns.

Ratio

Set the --ratio CSS variable to a number between 0 and 1 to change how much of the width the left pane takes. Defaults to 0.5. Everything is plain CSS, so changing the variable at any time re-lays out the panes.

Gap

Set --gap to change the space between the panes. Defaults to 1rem.

Resizable

Add the resizable attribute to let the midline be dragged. Dragging rewrites --ratio on the element itself, so the ratio stays readable as split.ratio and settable the same way. The handle fires input while dragging and change when the drag ends, both with detail.ratio. It is focusable too: arrow keys nudge by step (0.01 by default), Home / End jump to the ends. Set min and max to keep either pane from collapsing.

Left
Right

Divider

Set --divider to a border shorthand value to draw a line down the middle of the gap. Unset by default, so no line is drawn. The grab area around it is --handle-width wide, 0.75rem by default.
