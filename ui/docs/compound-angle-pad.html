Compound angle pad

A label, a help line, an angle-pad, and a number field per handle, composed into one panel-ready control for a pair of angles in degrees.

Basic

Dragging a handle or typing in a field keeps both in sync. Emits input while dragging and change on release or on a typed value, both with {angle1, angle2}.
