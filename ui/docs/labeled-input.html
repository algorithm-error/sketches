Labeled input

Like labeled select and labeled number input, but generic: it doesn't construct a control itself, it just labels and lays out whatever's slotted in — a plain <input>, a <select>, a color swatch group, anything that reflects a disabled attribute and fires change. Forwards disabled and stretch to the slotted control, and relays its change event with detail.value read off event.target.value. An optional help attribute adds a line of help text under the label.
