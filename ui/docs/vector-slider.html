Vector slider

A label, a help line, a vector pad, and a linked pair of number inputs that can show either cartesian (x, y) or polar (length, angle) coordinates, composed into one control. mode is a plain attribute, not an in-widget toggle — set it from the page (or bind it to your own control) to pick which pair of numbers is shown and editable. Dragging the pad always works the same way regardless of mode.

Basic

Dragging the pad or typing in either number field keeps everything in sync. The number fields update instantly while dragging; a change event with {x, y, length, angle} fires once the drag ends (or a field commits), and a debounced input event fires continuously while dragging — control its cadence with debounce (default 100ms, same as the other sliders).

Starting in polar mode

Set mode="polar" to start with length/angle shown instead of x/y.

Point instead of vector

Add point to pass it through to the pad, dropping the line back to the middle. Use it when the pair is a position rather than a vector — an origin on a canvas, for instance. Pair it with a --ratio matching that canvas so the pad box is the same shape.
