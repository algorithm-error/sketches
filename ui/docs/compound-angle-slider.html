Compound angle slider

A label, a help line, an angle slider, and a linked number field, composed into one panel-ready control for a single angle in degrees — the one-handle counterpart of the compound angle pad. Use it wherever the value is a direction: a track has ends, and a direction wraps past them.

Basic

Dragging the dial or typing in the field keeps both in sync and dispatches change with detail.value. 0° points right and angles run clockwise, matching p5.Vector.fromAngle on a canvas whose y grows downwards.

Size

size="medium" gives the dial the same box as the angle pad's, for a panel that mixes the two.
