Color swatch group

A single component owning a set of square color swatches. Unlike composing several standalone radio-backed elements (each with its own Shadow DOM, so native radio grouping can't cross them), every swatch here is a plain <input type="radio"> living in one Shadow DOM — the browser enforces "only one checked" natively.

Basic

Each color in the comma-separated colors attribute doubles as its own value; an optional parallel labels attribute sets accessible names. Dispatches change with detail.value.
