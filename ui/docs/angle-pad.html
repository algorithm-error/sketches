Angle pad

A dial carrying two independent angles, in degrees, on one track. Same geometry and convention as angle-slider (0° east, increasing clockwise) — reach for that one when you only need a single angle. The two handles are unrelated values sharing a dial, so either can pass the other; there is no range to keep ordered. Drag a handle, or click anywhere else in the dial to move whichever handle is already closest. Arrow keys move a focused handle by step, Home/End jump to min/max.

Basic

Fires input continuously while dragging and change once the drag ends, both with {angle1, angle2}.

40, 330

Range and step

Defaults span the full circle (min="0", max="360", step="1"), which wraps. A narrower min/max stops wrapping and clamps both handles to the arc.

30, 120

Size

The dial is small by default. size="medium" grows it to the same box as a vector pad, worth it when the two handles sit close together.

46, 40

Colors

The first handle uses --fill (defaulting to --primary), the second --fill-2 (defaulting to --red).
