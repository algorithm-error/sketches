Control row

A layout wrapper. Defaults to 1 1, two equal-width columns. Set the --columns CSS variable to a space-separated ratio — 1 1 1 for three equal columns, 3 2 for a 60% / 40% split — or to none for a plain row with an even gap and no enforced width.

Basic

Children are laid out as 1 1, two equal-width columns, by default.

One Two

Equal columns

Each number in the ratio is one column. Use 1 1 1 for three equal columns spanning the full width.

One Two Three

Uneven columns

The numbers are shares of the full width, so 3 2 gives a wide column at 60% and a narrow one at 40%.

Wide Narrow

Row
