Coordinate input

Two number inputs for a coordinate pair, showing either cartesian (x, y) or polar (length, angle) — set with the mode attribute, a plain prop rather than an in-widget toggle. min/max/step/size apply to both fields in cartesian mode; in polar mode length is clamped to 0+ and angle to 0–360. Dispatches change with detail.x, detail.y, and detail.value (an "x,y" string) regardless of mode.
