Compound slider

A label, a help line, a slider, and a linked number input, composed into one control.

Basic

Dragging the slider or typing in the number field keeps both in sync and dispatches a single change event with the numeric value.

No help

Vertical

Set direction="vertical" — the number input moves above the track and the label moves below it. The layout narrows to a column, so two or three fit side by side in a control-row inside a standard panel, alongside regular horizontal sliders.
