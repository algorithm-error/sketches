Angle slider

A round knob for picking an angle. Value is in degrees using p5's convention: 0° points east, increasing clockwise. Drag the knob (or click the ring) to set it; arrow keys, Home and End work once it's focused.

Basic

Default range is a full 0–360° circle, and the value wraps past either end.

0°

Restricted arc

Setting min/max narrower than 360° clamps the knob to that arc instead of wrapping.
