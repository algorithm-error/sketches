Vector pad

A 2D pad for picking a point/vector by dragging, square unless --ratio says otherwise. x and y increase left-to-right and top-to-bottom, matching p5's canvas and angle-slider's convention (0° east, increasing clockwise), so length/angle read off the element line up with values from an angle-slider. Drag the knob (or click the pad) to set it; arrow keys work once it's focused.

Basic

Default range is -1 to 1 on both axes. Fires input continuously while dragging and change once the drag ends.

0.3, -0.5

Custom range

Set min/max to change the range shared by both axes, and step to snap dragged/keyboard values.

20, 70

Box ratio

The pad is square by default. Set the --ratio custom property to width over height to match whatever the pad stands in for — a 16:9 canvas is --ratio: 1.778. Only the box changes shape: both axes still span min to max, and the knob stays round.

0.5, 0.95

Point mode

By default the knob is drawn as a vector: a line from the middle of the pad out to the value. Add point when the value is a plain position rather than a vector — an origin on a canvas, say — and the line and its hub go away, leaving just the knob.

0.5, 0.95

Polar mode

Set mode="polar" to swap the square track for an inscribed circle, signaling a length/angle reading. It's a visual cue only — the drag area and mapping stay the square described above, so the knob can still reach the corners.

0.5, 0.5
